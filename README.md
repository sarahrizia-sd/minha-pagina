# Minha-Pagina

# 🌾 Onychinus Farm – Diário da Sarah

Site sobre a minha personagem do **Stardew Valley**: onde ela mora, família, amizades, animais e conquistas.

🔗 **Ver o site:** https://sarahrizia-sd.github.io/minha-pagina/

## O que a página faz

- 🌙 **Botão dia/noite**: troca o tema com `if/else` e lembra a escolha com `localStorage`
- ❤️ **Jogo "Adivinhe os corações"**: lê o que foi digitado e valida campo vazio, letras e números fora do intervalo
- 🐖 **Lista de amizades e de animais**: montadas com arrays e laço `for`, com filtro de "mais felizes"

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `index.html` | estrutura da página |
| `estilo.css` | cores, layout e modo noite |
| `script.js` | toda a parte interativa |
| `img/` | prints do jogo |
